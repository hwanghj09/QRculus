## 0. 다른 AI에게 주는 필수 실행 지침

당신은 아래 조건을 만족하는 **로컬 재현형 Python 연구 프로젝트**를 구현해야 한다. 사용자에게 추가로 선호도를 묻지 말고 고정 규격을 따른다.

1. QR 버전 1, 메시지 `TEST01`, 마스크 1, 오류 정정 L/M/Q/H, 모듈당 10픽셀, 사방 4모듈 여백을 고정한다.
2. QR코드의 **데이터·오류정정 모듈 208개**만 손상한다. 위치 탐지·구분·타이밍·형식 정보·고정 검정 모듈은 보존한다.
3. 손상은 흑백 모듈 반전(XOR 1)이며, 손상률은 **손상 가능 208개 모듈을 분모**로 계산한다. 전체 픽셀 면적의 손상률로 명명하지 않는다.
4. L/M/Q/H × 손상률 18개(0, 0.5, ..., 8.0, 10.0%) × 각 100회의 본실험을 실행한다. 총 7,200회 판독 시도이다.
5. `np.random.default_rng(2026 + trial)`을 사용해 같은 반복 번호에서 모든 등급의 좌표 선택 순서를 동일하게 한다. 같은 반복 내 손상률이 커지면 뒤집은 모듈 집합이 포함 관계가 되도록 한다.
6. OpenCV `QRCodeDetector.detectAndDecode()` 결과가 입력 메시지와 **완전 일치**할 때만 성공으로 기록한다.
7. 매 시행의 손상 모듈 수·실제 손상률·정확한 성공 여부·난수 시드·원본 해시를 CSV에 기록한다. 원본 4종, 손상 예시, 그래프, 실행 환경 로그를 저장한다.
8. 고2 **다항함수 미분·정적분**만을 핵심 계산에 사용한다. 지수·로그 미분, 확률밀도함수, 비선형 최적화 알고리즘, 변분법, 통계 검정 등은 필수 연구 수식에서 제외한다.
9. 일차 **구간별 보간 모델을 전 범위 정량 비교의 주 모델**로 사용하고, 급격히 하락하는 부분에서만 **국소 삼차 보간 모델을 심화 분석용**으로 사용한다. 삼차 다항식으로 전체 구간을 억지로 적합시키지 않는다.
10. 본실험을 실행하기 전까지 과거 예비 실험의 성공률과 본실험을 혼합하지 않는다. 예비 실험값은 예시로만 표시한다.
11. 실행 환경과 시드가 같아도 OpenCV·패키지·플랫폼이 다르면 판독 결과가 바뀔 수 있으므로 버전을 기록한다.
12. 마지막으로 학교 조건에 맞는 **A4 최대 3쪽 PDF 보고서를 별도로 생성**하도록 코드를/프롬프트를 정리하되, 이 상세 명세서 자체를 3쪽으로 억지로 줄이지 않는다.

### 0.1 용어 정의 (혼동 금지)

- **모듈(module):** QR 내부의 작은 흑백 정사각형 하나. 버전 1은 21×21=441개 모듈이다.
- **손상 가능 모듈(eligible module):** QR 버전 1에서 예약 기능 패턴을 제외하고 데이터·오류정정 비트가 배치되는 208개 모듈.
- **손상 횟수:** 서로 다른 모듈을 `k`개 선택하여 각각 흑백을 한 번 반전시킨 것. 동일 모듈을 중복 선택하지 않는다.
- **설정 손상률(`target_pct`):** 실험 계획에서 지정한 백분율. 정수 모듈 수로 반올림하므로 실제 손상률과 다를 수 있다.
- **실제 손상률(`actual_pct`):** `100 × k / 208`. 표·도함수·적분의 x축에는 가능한 한 이것을 사용한다.
- **복원 성공률(`success_pct`):** `100 × (원문과 동일하게 판독한 횟수) / 총 시행 횟수`. QR 위치를 찾은 것만으로 성공 처리하지 않는다.
- **오류 정정 등급:** L·M·Q·H. DENSO WAVE의 약 7/15/25/30%는 **코드워드 기준의 개략 복원 능력**이지 이 실험의 비트/모듈 반전률에 대한 성공 보장이 아니다.

## 1. 연구 목적·배경·필요성

QR코드는 정보를 작은 흑백 격자에 저장하는 2차원 코드이며 일부 정보가 손상되어도 오류 정정 과정을 통해 원래 문자열을 읽을 수 있다. 그런데 공식 오류 정정 등급의 수치만으로는 특정 위치의 모듈 몇 개가 손상되었을 때 **실제 판독 성공률**이 어떻게 변하는지 알 수 없다. 손상 비율에 대한 결과는 손상 위치, QR 데이터 배치, 오류 정정 등급, 판독기의 구현에도 영향을 받기 때문이다.

이 연구는 QR코드를 직접 생성하고 손상시키는 컴퓨터공학 실험을 수행한 뒤, 그 결과를 고등학교 미적분Ⅰ의 다항함수로 근사하여 **(가) 성공률의 급락 구간, (나) 가장 빠른 감소 지점, (다) 손상률 범위 전체에서의 평균 복원 성능**을 수학적으로 해석하는 것을 목표로 한다.

학문적 의미는 새 QR 오류 정정 알고리즘을 발명하는 데 있지 않다. **실험 데이터를 이용해 함수식을 직접 만들고, 그 함수의 도함수와 정적분이 실제 시스템의 어떤 성질을 의미하는지 검증하는 것**이다.

## 2. 연구 질문·가설·판정 기준

| 구분 | 연구 질문 | 가설 / 검증 논리 |
|---|---|---|
| RQ1 | 데이터 모듈의 실제 변경률이 증가할 때 정확한 판독 성공률은 어떻게 달라지는가? | 낮은 손상률에서는 높다가 일부 구간에서 급격히 하락할 것으로 예상한다. 단 개별 시행의 판독 성공은 반드시 단조 감소한다고 가정하지 않는다. |
| RQ2 | 성공률이 가장 빠르게 떨어지는 손상률 또는 손상률 구간은 무엇인가? | 실측 점 사이의 기울기 중 가장 작은 값(주 분석)을 찾고, 국소 삼차 보간의 도함수 최솟값(심화)을 계산한다. |
| RQ3 | 오류 정정 등급별 전체 복원 성능은 얼마나 차이 나는가? | 동일한 손상 범위 [0,10%]에서 구간별 정적분으로 계산한 **평균 성공률**을 비교한다. 일반적으로 H가 유리할 것으로 예상하지만 모든 데이터에서 무조건 이 순서라고 강제하지 않는다. |
| RQ4(선택) | 실험값 4개로 만든 삼차함수는 다른 실측값도 잘 예측하는가? | 함수에 사용하지 않은 중간 손상률이나 별도 반복 결과를 예측하여 절대 오차를 계산한다. |

- **입증할 내용:** 이 고정 설정에서 성공률-손상률의 경험적 함수적 관계 및 수학적 해석.
- **입증하지 않는 내용:** 모든 QR코드, 스마트폰 카메라, 종이 인쇄물, 다양한 마스크·버전에서의 보편적 복원 법칙.

## 3. 수학 교과 범위와 연구의 연결

| 미적분Ⅰ 범위 | 반드시 수행할 분석 | 의미 |
|---|---|---|
| 다항함수 | 실험 데이터로 일차 또는 삼차함수의 계수 결정 | 관찰값을 수학식으로 표현 |
| 미분계수·도함수 | 성공률 함수 `R'(x)` 계산 | 손상률이 조금 증가할 때 성공률 변화의 속도 |
| 함수의 증가·감소와 극값 | 도함수의 부호, 이차함수 꼭짓점 비교 | 성공률이 빠르게 감소하는 구간 또는 지점 발견 |
| 정적분 | `∫ R(x) dx` 계산 | 일정 손상 구간의 성공률 곡선 아래 넓이 |
| 정적분의 응용 | `1/(b-a) ∫_a^b R(x) dx` | 그 구간 전체의 **평균** 성공률 |

실험에서 난수와 성공 횟수의 빈도를 세는 행위는 컴퓨터 실험 방법이지만, **제출할 핵심 수학적 전개는 다항식·연립방정식·도함수·정적분에 한정**한다. 삼차함수의 도함수는 이차함수이고, 이차함수의 꼭짓점은 고등학교 함수 개념만으로 구한다.

### 4.3 모듈 변경 개수와 손상률 환산

손상 가능한 모듈의 총수는 `N=208`이다.

```
k = round_half_to_even(N * target_pct / 100)
actual_pct = 100 * k / N
```

Python 내장 `round()`의 반올림 규칙을 그대로 적용한다. 반올림이 개입하므로 x축 데이터는 **설정 손상률과 실제 손상률을 모두 기록**해야 한다.

| 설정 손상률 | 반전 모듈 수 k | 실제 손상률 |
|---:|---:|---:|
| 0.0% | 0 | 0.0000% |
| 0.5% | 1 | 0.4808% |
| 2.0% | 4 | 1.9231% |
| 4.0% | 8 | 3.8462% |
| 5.0% | 10 | 4.8077% |
| 8.0% | 17 | 8.1731% |
| 10.0% | 21 | 10.0962% |

**본 연구의 수치 분석 공식에 실제 손상률을 대입**하고, 예비 코드에서 설정 손상률을 사용한 개략 비교와 구분한다. 특히 설정 손상률 8~10% 사이에는 실제 모듈 손상 개수 간격이 넓다.

## 5. QR코드 생성 사양

1. `qrcode.QRCode(version=1, error_correction=LEVEL_CONSTANT, box_size=10, border=4, mask_pattern=1)` 객체를 만든다.
2. `qr.add_data('TEST01')`을 실행한다. 한 개 메시지 외 다른 데이터는 추가하지 않는다.
3. `qr.make(fit=False)`로 버전 자동 확장을 금지한다.
4. `qr.modules`를 21×21 `uint8` 배열로 변환한다. 요소는 0/1이어야 하며 모양이 다르면 즉시 중단한다.
5. 사방 4모듈을 0으로 패딩한 후 각 모듈을 정확히 10×10 픽셀로 확장한다(`np.kron` 등을 사용). 출력은 흰색=255, 검정=0의 grayscale PNG다.
6. 4등급 원본을 각각 `original_L.png`, `original_M.png`, `original_Q.png`, `original_H.png`에 저장한다.
7. OpenCV로 원본 QR을 읽어 결과 문자열이 정확히 `TEST01`이 아니면 본실험을 **중지**한다.
8. 각 QR 모듈 배열을 정규화된 행렬 데이터·해시로 기록해 코드/환경 변화에 따른 QR 배치를 추적한다.

> H 등급은 더 많은 오류 정정 코드워드를 사용하므로 같은 21×21 그리드에도 코드워드의 분포가 달라진다. 네 등급의 **동일한 물리 좌표**를 뒤집되 실제 데이터 비트의 의미가 같다고 가정하지 않는다.

## 6. 핵심 구현 — 손상 대상 모듈 마스크

### 6.1 모듈 좌표계

- (0,0): QR 내부 행렬의 왼쪽 위.
- 좌표 `(row, col)`은 각각 0~20 범위.
- PNG 테두리의 정숙 구역 4모듈은 실험 대상이 **아니다**.
- QR 기능 정보와 모듈을 손상시키지 않는 것이 주목적이므로 **버전 1 전용의 예약영역 마스크**를 사용한다. 상위 버전으로 일반화하려면 다시 검증해야 한다.

### 6.2 예약영역 지정 — 필수 알고리즘

```python
reserved = np.zeros((21, 21), dtype=bool)

# 세 위치 탐지 패턴과 주변 흰색 분리 영역
reserved[0:8, 0:8] = True
reserved[0:8, 13:21] = True
reserved[13:21, 0:8] = True

# 두 복제본으로 배치되는 형식(format) 정보
reserved[8, 0:9] = True
reserved[8, 13:21] = True
reserved[0:9, 8] = True
reserved[13:21, 8] = True

# 타이밍 패턴
reserved[6, :] = True
reserved[:, 6] = True

# 고정 다크 모듈
reserved[13, 8] = True

eligible_coords = np.argwhere(~reserved)  # [row, col] 순서, 행 우선 정렬
assert len(eligible_coords) == 208
assert reserved.sum() == 233
```

오류 정정용 코드는 데이터 배치 영역에 함께 존재하므로 `eligible_coords`는 **순수 메시지 데이터만**이 아니라 데이터 및 오류 정정 모듈 전체를 포함한다. 이 해석을 보고서에 그대로 표시한다.

### 6.3 손상 알고리즘 — 전체 규칙

```text
for level in [L, M, Q, H]:
    original = generate_qr(level)
    verify_decode(original) == "TEST01"

    for trial in 0..99:
        seed = 2026 + trial
        permutation = default_rng(seed).permutation(208)
        for target_pct in [0,0.5,1,...,8,10]:
            k = round(208*target_pct/100)
            coords = eligible_coords[permutation[:k]]
            damaged = original.copy()
            for row,col in coords:
                damaged[row,col] = 1 - damaged[row,col]
            png = render_290x290(damaged)
            decoded, points, rectified = detector.detectAndDecode(png)
            correct = int(decoded == "TEST01")
            append_trial_row(level,trial,seed,target_pct,k,100*k/208,decoded,correct)
```

**재현성 상세 규칙:**

- `np.argwhere()`가 반환하는 208개 좌표의 **기본 행 우선 순서**를 유지한다. 좌표 배열을 사용자 마음대로 정렬하거나 무작위로 다시 섞지 않는다.
- `default_rng(seed).permutation(208)`을 등급별 반복마다 **동일한 순서로 재생성**한다. 반복 번호가 같으면 L·M·Q·H의 선택된 물리 좌표가 같도록 한다.
- 같은 반복 번호 내에서 손상률 1%의 손상 집합은 2%의 집합에 포함된다. 다른 반복 번호 간에는 독립적인 난수 순서를 사용한다.
- 파괴적 수정 방지: 각 손상 조건마다 **반드시 원본에서 복사**하여 뒤집는다. 이전 손상 이미지를 다시 뒤집으면 안 된다.
- 좌표 중복 제거 필요 없음. permutation이 중복 없는 순열을 생성한다.
- 검출 못함(`decoded=''`), 잘못 읽힘(`decoded!='TEST01'`), 예외(원인 기록) 모두 성공과 구분해서 원자료에 저장한다. 예상하지 못한 프로그램 예외는 묵살하지 말고 실패 로그와 함께 실행 중단/복구 정책을 명시한다.
- 성능 향상을 위해 판독기를 재사용할 수 있으나, 각 판독은 독립적인 290×290 8bit 배열에서 실행한다.

## 9. 수학적 분석 명세 — 미적분Ⅰ만 사용

### 9.1 측정값과 함수의 차이

각 실험에서 `correct`는 0 또는 1이고, 같은 조건을 100회 실행해 그 평균에 100을 곱한 수치가 성공률이다. 실험으로 얻은 `(x_i, y_i)`는 **이산점**이므로 그 자체를 연속적으로 미분·적분할 수 없다. 따라서 먼저 이 점들 사이의 함수를 **직접 정의하거나 근사**한 다음 그 모델을 미분·적분한다. 이것이 연구의 가장 중요한 논리적 단계다.

### 9.2 1차 분석: 구간별 일차함수의 정확한 정적분

`x_i`는 **실제 손상률(%)**, `y_i`는 **성공률(%)**이고 `x_i < x_(i+1)`이라고 하자. 인접한 두 측정점 사이를 직선으로 잇는다.

```
R_i(x) = y_i + ((y_(i+1)-y_i) / (x_(i+1)-x_i)) * (x-x_i)
           for x_i <= x <= x_(i+1)
```

이때 기울기

```
m_i = (y_(i+1)-y_i) / (x_(i+1)-x_i)
```

는 해당 구간에서의 성공률 변화율이다. `m_i`가 가장 작은 구간이 **관찰 범위에서 성공률이 가장 가파르게 감소한 구간**이다. 성공률 0~100 밖의 예측 없이 전 범위를 표현할 수 있다(단, 인접한 실측 성공률 자체는 유효한 비율이어야 한다).

구간별 적분:

```
∫[x_i to x_(i+1)] R_i(x)dx = (y_i + y_(i+1))/2 * (x_(i+1)-x_i)
```

전체 평균 복원 성공률:

```
R_bar = (1/(x_n-x_0)) * Σ_i [(y_i+y_(i+1))/2 * (x_(i+1)-x_i)]
```

이것은 사다리꼴의 근삿값을 외운 것이 아니라, **각 구간을 실제로 일차함수로 정의했으므로 그 모델에 대한 정적분은 정확히 위 값이 된다**는 뜻이다. 단, 실제 미지의 성공률 곡선에 대한 정확한 적분이라는 뜻은 아니다.

### 9.3 2차 심화 분석: 국소 삼차함수 유도

성공률이 급격히 떨어지는 구간에서 손상률이 연속적인 것처럼 근사하고, **미리 정한 4개 점**으로 다항함수를 결정한다.

- 우선 본실험에서 가장 가파른 인접 구간을 찾는다.
- 그 구간을 포함하고 변경 모듈 수가 연속인 **4개 이웃한 k 값**을 선택한다. 주의: 실험률 그리드가 1개씩 증가하지 않는 끝부분(8→10%)은 기본적으로 국소 삼차함수 후보에서 제외한다.
- `u = k - k0`를 쓰고 네 실측값 `(u,y)=(0,y0),(1,y1),(2,y2),(3,y3)`를 선정한다.
- 연립방정식으로 `P(u)=au³+bu²+cu+d`의 계수 4개를 계산한다.
- 함수의 유효 범위는 **[0,3]**으로 제한한다. 원점이나 x를 기호로 바꿔 표기한 경우 설명을 병기한다.
- 원래 손상률 단위로 변환하려면 `x=100*(k0+u)/208` 및 `u=208*x/100-k0`를 사용한다.

연립방정식:

```
d               = y0
a+b+c+d         = y1
8a+4b+2c+d     = y2
27a+9b+3c+d    = y3
```

미분:

```
P'(u) = 3a u² + 2b u + c
```

**가장 빠른 감소 지점:** `P'(u)`라는 이차함수가 구간 [0,3]에서 최소가 되는 곳을 비교한다. `a>0`이면 꼭짓점 `u*=-b/(3a)`가 [0,3] 안에 있는지 확인하고 양 끝점과 비교한다. `a<=0`일 때도 구간의 양 끝점 등에서 최소값을 비교한다. `a=0`이면 모델이 삼차가 아니라 이차 이하라는 사실을 기록한다. 이 과정에 이계도함수는 필수가 아니다.

**물리적 해석의 주의:** `k`는 정수이므로 `k=9.67`처럼 연속 모델이 예측하는 값은 **전환 구간의 위치를 추정**한 것이다. 분수 개의 모듈을 실제로 뒤집을 수 있다고 주장하지 않는다.

**단조성과 유효성 검증:** 국소 삼차함수가 [0,3] 안에서 0% 미만, 100% 초과를 예측하거나, 실험 방향과 무관하게 비정상적으로 크게 진동하면 심화 모델로 해석하지 않고 구간별 일차함수를 유지한다. 국소 모델 선택·해석 기준을 사후에 유리하게 바꾸지 않는다.

### 9.4 국소 삼차함수의 정적분

```
P_bar = (1/3) * ∫[0 to 3] (a u³ + b u² + c u + d)du
      = (1/3) * [ (a/4)u⁴ + (b/3)u³ + (c/2)u² + du ](0 to 3)
```

이 값은 **선택한 4점 사이 구간의 모델 평균 성공률**이며, 전 범위 평균 성능과 같지 않다. 등급을 비교할 때는 다른 구간의 국소 평균끼리 비교하지 말고 9.2의 **동일 전체 범위 평균**을 우선한다.

### 9.5 검증·오차

- 국소 다항식이 사용한 네 점에서 일치하는 것은 **보간의 정의상 당연한 사실**이며 이것만으로 모델 정확성이 입증되지 않는다.
- 평가 방법: 별도 반복 데이터(예: 본실험 100회에서 학습 70회/검증 30회로 선분리)로 얻은 성공률을 예측값과 비교한다. 임의 표본 선택은 별도 고정 시드로 하되 분석 시드까지 기록한다.
- 그러나 **4점 보간식의 내부 중간 x 값에 관측값이 없으면** 그 구간의 예측을 독립적으로 검증했다고 주장하지 않는다. 검증용 보조 실험으로 새로운 QR 문자열이나 마스크를 바꾸지 않은 채 동일 손상률의 새 난수 시드를 추가하고, 같은 k에서 성공률을 비교한다. 이 검증은 동일 손상률 점의 측정 오차를 평가하지만, 4점 사이의 미관측 연속 구간을 검증하는 것은 아니다.
- 보간 밖 데이터 예측은 단지 보조 점검이며 외삽 일반화로 결론 내지 않는다.
- 각 조건당 100회이므로 측정 성공률은 1%p 단위로만 변한다. 작은 차이는 과잉 해석하지 않는다.

## 10. 이미 존재하는 예비 실험 — 본실험과 분리

> 2026-11-14 작성된 **기존 실험 파일에서 확인한 결과**. 고정 조건: QR 버전1, 메시지 `TEST01`, 마스크1, OpenCV 판독, 손상 가능한 모듈 208개, 조건당 **20회**. 이 데이터는 설명용이며 예정된 100회 본실험의 결과가 아니다.

| 설정 손상률 | L | M | Q | H |
|---:|---:|---:|---:|---:|
| 0% | 100% | 100% | 100% | 100% |
| 2% | 20% | 100% | 100% | 100% |
| 3% | 0% | 20% | 100% | 100% |
| 4% | 0% | 0% | 20% | 100% |
| 5% | 0% | 0% | 0% | 40% |
| 6% | 0% | 0% | 0% | 10% |
| 7% | 0% | 0% | 0% | 0% |

예비 실험의 H 등급에서 **변경한 모듈 개수** `k=8,9,10,11`에 대한 성공률은 `100,80,40,10`이었다. 이 네 값으로 국소 삼차함수를 보간하면:

```
u = k - 8,     0 <= u <= 3
P(u) = 5u³ - 25u² + 100
P'(u) = 15u² - 50u
```

`P'`가 [0,3]에서 최소인 값은 `u=5/3`. 따라서 `k=8+5/3≈9.67개`, `actual_pct≈4.65%` 부근에서 **국소 모델상 변화율이 가장 작다**고 해석한다.

```
(1/3) ∫[0 to 3] P(u)du = 58.75%
```

**중요:** 58.75%는 **k=8~11이라는 짧은 국소 구간의 평균값**이고, 기존 예비 데이터의 전구간 평균(설정 손상률 x축으로 계산한 값과 구분)은 따로 계산해야 한다. 본실험 후에는 반드시 본실험의 함수 계수와 수치로 교체한다.

## 15. 위험·한계·사전 결정

1. **QR코드 공식 30%의 의미:** 코드워드 단위의 대략적 복원 능력. 모듈 30% 반전 실험과 비교해 표준 불일치라고 결론 내리지 않는다.
2. **데이터 영역 정의:** 208개에는 메시지와 오류 정정 코드워드 영역이 함께 포함되며, 가림/훼손 대신 XOR 반전이다. 따라서 실제 인쇄물의 얼룩·훼손과 다르다.
3. **판독기 의존성:** OpenCV QRCodeDetector의 버전과 내부 구현에 따라 결과가 달라질 수 있다.
4. **모델의 한계:** 다항식은 데이터를 설명하는 경험적 함수일 뿐 QR 오류 정정의 수학적 메커니즘 그 자체가 아니다.
5. **극값 오해 방지:** 복원 성공률 `R(x)`의 최솟값은 보통 0% 구간에서 나타나 탐구 가치가 낮다. 따라서 **도함수 `R'(x)`가 가장 작아지는 지점**을 주요 결과로 본다.
6. **표본 변동:** 동일 조건이라도 손상 좌표에 따라 결과가 달라지므로 같은 난수 시드를 써야 재현 가능하다. 반복 100회 이상은 권장값이 아니라 **이 프로젝트의 확정 본실험 조건**이다.
7. **QR 원본이 인식 실패할 때:** 시작 조건이 성립하지 않으므로 기록 후 중단. 메시지·마스크·오류 정정 등급을 임의로 바꿔 통과시킨다면 연구 설계를 변경했다고 표시해야 한다.
8. **예비 실험의 재실행:** 환경에 따라 기존 예비 데이터와 결과가 완전히 동일하지 않아도 된다. 원인이 뭔지 추적할 수 있도록 원본/이미지 해시와 라이브러리 버전을 기록한다.
9. **삼차 모델이 실패할 때:** 삼차 보간이 유효 범위를 벗어나거나 부자연스러운 진동을 보이면 국소 해석을 보조로만 제시하고, 구간별 일차함수와 그 도함수/정적분으로 핵심 분석을 수행한다.
10. **사용자 제출:** 실제 학번·이름 등은 보고서 생성 시 별도 입력한다. 본 프로젝트 명세에 임의의 개인 식별정보를 만들어 넣지 않는다.

## 17. 인수인계 시 최종 응답 형식(다른 AI용)

다른 AI는 구현 완료 후 다음 내용을 반드시 보고한다.

1. 작성한 파일 목록과 실제 파일 경로.
2. 설치·실행·스모크·본실험·분석·PDF 생성의 **실제 실행 명령어**.
3. 통과/실패한 테스트 ID와 실행 출력 요약.
4. 결과 파일 행 수: 시행 7,200, 집계 72.
5. 등급별 가장 빠른 감소 구간과 전체 적분 평균 성공률(실측 계산).
6. 국소 삼차식의 사용 구간과 계수 및 예측 오류.
7. 예비 데이터인지 본실험 데이터인지 명확한 표시.
8. PDF의 페이지 수, 수식과 한글의 렌더링 검수 여부.
9. 재현성 정보(시드·환경 버전·입력값·이미지 해시 기록).
10. 남은 제약과 과장하면 안 되는 결론.

미완성 기능이 있으면 완료했다고 주장하지 말고 구현된 범위와 누락된 범위를 구체적으로 적는다.

## 18. 참고문헌과 사용 근거

아래는 공개 표준·공식 자료이며 본 프로젝트의 설계에 직접 사용한 출처다.

1. **DENSO WAVE.** 「오류 복원 기능에 대해」. QRcode.com. <https://www.qrcode.com/ko/about/error_correction.html> (오류 정정 등급, 코드워드의 의미, 리드-솔로몬 원리).
2. **DENSO WAVE.** 「QR코드의 정보량과 버전」. QRcode.com. <https://www.qrcode.com/ko/about/version.html> (버전 1=21×21 구조).
3. **ISO.** *ISO/IEC 18004:2024: QR code bar code symbology specification*. <https://www.iso.org/standard/83389.html> (QR 표준 존재 및 규정 범위; 유료 표준의 전문이 본 문서에 재현되지는 않음).
4. **Python qrcode package.** *qrcode 8.2 — PyPI*. <https://pypi.org/project/qrcode/8.2/> (QRCode 생성·버전·오류 정정 등급·quiet zone).
5. **OpenCV.** *QRCodeDetector API*. <https://docs.opencv.org/4.x/de/dc3/classcv_1_1QRCodeDetector.html> (detectAndDecode 기능).
6. **NumPy.** *Random Generator API*. <https://numpy.org/doc/stable/reference/random/generator.html> (`default_rng`, `permutation`; 버전 변경 시 재현성 점검).

**출처 관리 규칙:** QR 표준에 대한 사실 설명에는 1~5의 자료를 인용하고, 실제 성공률·함수 계수·그래프는 인터넷 출처가 아니라 **내 실험 원자료 CSV와 코드·시드·실행 환경**을 출처로 명시한다.
