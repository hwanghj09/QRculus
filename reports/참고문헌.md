# 참고문헌·출처

1. DENSO WAVE, 오류 복원 기능. 오류 정정 등급별 코드워드 기준 복원 능력과 리드–솔로몬 개요. <https://www.qrcode.com/ko/about/error_correction.html>
2. DENSO WAVE, QR코드의 정보량과 버전. 버전 1의 21×21 규격. <https://www.qrcode.com/ko/about/version.html>
3. ISO/IEC 18004:2024, *QR code bar code symbology specification*. QR 규격 식별 정보. <https://www.iso.org/standard/83389.html>
4. qrcode 8.2, PyPI. QR 생성 옵션. <https://pypi.org/project/qrcode/8.2/>
5. OpenCV, QRCodeDetector API. `detectAndDecode` 판독. <https://docs.opencv.org/4.x/de/dc3/classcv_1_1QRCodeDetector.html>
6. NumPy, Random Generator API. `default_rng` 및 `permutation`. <https://numpy.org/doc/stable/reference/random/generator.html>

본실험 수치의 출처는 직접 실행한 [원자료](../results/final/trials.csv), [집계](../results/final/success_rate.csv), [실행 환경](../results/final/environment.json), [모델 계산 결과](../results/final/analysis_details.json)다. 추가 검증은 [새 시드 시행 자료](../results/final/local_validation_trials.csv)를 사용했다.
